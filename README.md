🚀 SkillVerse: Your Tech Career CompassAwarded with the IBM & UTEL University Hackathon Recognition Recognized for innovation, professional execution, and high technical standards in educational technology.SkillVerse is an educational demo platform designed to connect users with the most relevant job opportunities in the tech sector. Our mission is to bridge the gap between market demand and user skills by offering clear learning paths based on geographic data and real-time technology trends.🏆 IBM Hackathon AchievementThis project was selected for professional recognition by IBM and UTEL University for its potential impact on the developer community and its clean, scalable implementation of core web technologies.💡 Key Features (Demo)Geographic Validation: Identifies the user’s location to provide a localized job market analysis.Tech Demand Analysis: Evaluates and highlights the most in-demand technologies and skills in the selected region (e.g., JavaScript, React, Python).Personalized Learning Paths: Suggests relevant courses and mock exams based on the identified skill gap.🛠️ Tech Stack (Demo)The SkillVerse prototype was built using enterprise-standard Front-end fundamentals:TechnologyPurposeHTML5Semantic web structure and SEO-friendly layout.CSS3Modern, responsive styling with a clean and professional UI.JavaScript (ES6+)Core demo logic, simulated geographic validation, and dynamic course/exam generation.⚙️ Local Installation & ExecutionTo view and test the SkillVerse demo in your local environment, follow these steps:Clone the repository:Bashgit clone https://github.com/EnriqueRocha13/skillverse.git
